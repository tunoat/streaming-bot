# Streaming Bot MVP

โปรเจกต์ตัวอย่างสำหรับรันในเครื่อง ประกอบด้วยเว็บไซต์จำลองจัดการ Netflix (`NF-001`), Prime, HBO และ Disney โดยเลือกบริการได้จากหน้า Admin Control แต่ละบริการมีบัญชีและ Profile 1–5 ของตัวเอง พร้อมเปลี่ยนชื่อบัญชี/โปรไฟล์และจัดการ PIN ได้ Playwright headless bot ทดสอบการเลือกบริการ เปลี่ยน PIN และตรวจสอบ PIN ที่แสดง

> **ขอบเขต:** ข้อมูลและหน้าจอทั้งหมดเป็นข้อมูลจำลอง ไม่มีการเชื่อมต่อ Netflix, อีเมล หรือบริการภายนอก หน้า Admin Control ไม่แสดงการ์ดบริการ; เลือก Netflix (PIN 4 หลัก), Prime (5 หลัก), HBO (4 หลัก) หรือ Disney (4 หลัก) ได้จากฟอร์ม Bind Account รายการบัญชีที่ Bind แสดงเป็นกลุ่มตามบริการและใช้ Alias แทนอีเมล พร้อมค้นหาด้วย Alias มีปุ่ม X สำหรับล้างคำค้น และ F5 จะโหลดรายการที่ Bind ทั้งหมดใหม่ ระบบแสดง PIN ปัจจุบันบนการ์ดของแต่ละโปรไฟล์ และสุ่ม PIN ให้ตรวจสอบก่อนบันทึกได้ แต่ละโปรไฟล์กำหนดวันหมดอายุเองในรูปแบบ `วัน/เดือน/ปี` (รองรับปี พ.ศ.) หรือใช้ปุ่มรายวัน/สัปดาห์/เดือน/ปีได้ ปุ่มเคลียร์จะทำให้ว่าง นำโปรไฟล์ออก และหมุน PIN ในข้อมูลจำลอง เมื่อหมดอายุหรือเปลี่ยน PIN ระบบจำลองจะนำโปรไฟล์ออกและหมุน PIN ปุ่มค้นหาโปรไฟล์ว่างให้เลือกบริการเพื่อดูโปรไฟล์ว่างของทุกบัญชีที่ Bind และกดผลลัพธ์เพื่อเปิดโปรไฟล์ได้ ช่องรหัสผ่านรับค่าเดโมเท่านั้น ล้างทันที และไม่ส่ง/บันทึก เมื่อกดขอ OTP ระบบรอเล็กน้อย อ่าน OTP จากกล่องอีเมลจำลอง แสดงรหัสและสถานะสำเร็จ จากนั้นกดยืนยันเพื่อ Bind ไม่มีการล็อกอินหรืออ่านอีเมลจริง และไม่มีการแก้ CAPTCHA เปลี่ยน Alias ได้ไม่เกิน 60 ตัวอักษร และชื่อโปรไฟล์ไม่เกิน 40 ตัวอักษร ระบบ session, ชื่อ, PIN, วันหมดอายุ และรายการ bind เก็บในหน่วยความจำและจะเริ่มใหม่เมื่อปิดเว็บ เหมาะสำหรับทดลองเท่านั้น ไม่ใช่ระบบ production

## สิ่งที่ต้องมี

- Node.js LTS (Node.js 22.18 ขึ้นไป; โปรเจกต์นี้ทดสอบกับ Node.js 26)
- npm
- Windows 10/11

## ติดตั้งบน Windows

เปิด PowerShell หรือ VS Code Terminal ในโฟลเดอร์โปรเจกต์ แล้วรัน:

```powershell
npm install
Copy-Item .env.example .env
npx playwright install chromium
```

แก้ค่าใน `.env` ตามต้องการ โดยเฉพาะ `ADMIN_PASSWORD`, `SESSION_SECRET` และ PIN ตั้งต้น/ทดสอบของแต่ละบริการ ค่าของ Netflix/HBO/Disney ต้องเป็นตัวเลข 4 หลัก ส่วน Prime ต้องเป็นตัวเลข 5 หลัก ค่าเริ่มต้นที่เตรียมไว้ใช้สำหรับเดโมในเครื่องเท่านั้น

ถ้า PowerShell แจ้งว่าไม่พบ `node` หรือ `npm` หลังติดตั้ง Node.js:

1. กด `Win + R` พิมพ์ `sysdm.cpl` แล้วกด Enter
2. เลือก **Advanced → Environment Variables**
3. ใน **User variables** เลือก `Path` แล้วกด **Edit → New**
4. เพิ่ม `C:\Program Files\nodejs\` กด **OK** ทุกหน้าต่าง แล้วปิด/เปิด VS Code ใหม่
5. ตรวจสอบด้วย `node --version` และ `npm --version`

## เริ่มเว็บไซต์

```powershell
npm run dev
```

เปิด <http://127.0.0.1:3000> แล้วเข้าสู่ระบบด้วยค่า `ADMIN_USERNAME` และ `ADMIN_PASSWORD` จาก `.env` เลือก Netflix, Prime, HBO หรือ Disney บนหน้า Admin Control แล้วแก้ชื่อบัญชี/โปรไฟล์ ดู PIN ปัจจุบันบนการ์ดโปรไฟล์ และเปลี่ยน PIN ตามจำนวนหลักของบริการนั้นได้ ข้อมูลทั้งหมดเป็นข้อมูลจำลองสำหรับเดโมนี้เท่านั้น

## ทดสอบบอท

เปิด PowerShell/Terminal อีกหน้าต่างในโฟลเดอร์โปรเจกต์ ขณะที่เว็บไซต์ยังทำงานอยู่ แล้วรัน:

```powershell
npm run test:bot
```

บอทจะเปิด Chromium แบบ headless เข้าสู่ระบบ Bind บัญชีจำลองของทั้งสี่บริการ ขอ OTP, ตรวจสถานะสำเร็จและรหัส OTP จำลองที่แสดงบนหน้า แล้วกดยืนยัน Bind สุ่ม PIN และเปลี่ยน PIN ของ `Profile 3` ตามค่าทดสอบใน `.env` ทดสอบวันหมดอายุรูปแบบ `DD/MM/YYYY`, ปุ่มช่วงเวลาและการเคลียร์ให้ว่าง จากนั้นค้นหาโปรไฟล์ว่างและบัญชีด้วย Alias และแสดง `PASS` เมื่อขั้นตอนสำเร็จ

ตรวจสอบ TypeScript ได้ด้วย:

```powershell
npm run typecheck
```

## โครงสร้าง

- `demo-web/` — Express server, หน้า Admin Login, รายการโปรไฟล์ และฟอร์มเปลี่ยน PIN
- `bot-worker/` — Playwright bot สำหรับทดสอบขั้นตอน Profile 3
- `.env` — ค่าลับและค่าตั้งต้นเฉพาะเครื่อง (ไม่ถูก Git ติดตาม)
- `.env.example` — แม่แบบสำหรับสร้าง `.env`
